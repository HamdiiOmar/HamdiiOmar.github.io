CloudGuard v0.1 · early alpha

2026Personal projectPython · MIT

A small, testable multi-cloud security scanner (CSPM) for Azure and AWS. It checks configuration against rules mapped to the CIS Foundations Benchmarks and MITRE ATT&CK, and the same checks run on three inputs: Terraform code, a live AWS account or a live Azure subscription.

  • 16 checks (6 Azure, 10 AWS): public storage, open SSH/RDP, root access keys, missing MFA, wildcard IAM policies and more.
  • Collection is separated from evaluation, so every check is a plain Python function that is unit-tested without a cloud account.
  • The AWS collector is tested end to end against moto; the Terraform reader was run on TerraGoat (47 files), and the two bugs it found are now fixed and covered by tests.
  • Reports as console, JSON or SARIF 2.1.0 (Terraform findings carry file and line), with CI on GitHub Actions.

Home SOC Lab

2026Personal projectWazuh SIEM

A self-hosted, isolated security monitoring lab with an attacker, two targets and a SIEM. It goes beyond installing a SIEM with default rules: it covers custom detection logic and closes the loop from detection to automated defense.

  • Real attacks from Kali: SSH brute-force with Hydra, and SQL injection against DVWA.
  • Custom detection rule (id 100011, level 12) for SQLi in DVWA requests, mapped to MITRE ATT&CK T1190 and debugged with wazuh-logtest.
  • Automated response: a detected SSH brute-force triggers Active Response, which firewalls the attacker's IP with iptables and lifts the block after a timeout.
  • Custom live console: a dependency-free Node proxy and a React UI that poll the Wazuh indexer and show severity-coded alerts.
